# Dashboard concepts (30 Sep)

Five alternative looks for the main dashboard, same demo content. Open the HTML files in a browser (self-contained).

1. Clean Light: white, navy, sidebar navigation, Today beside the scoreboard.
2. Editorial: warm ivory, forest green and brass, serif headlines, numbered Today.
3. Enterprise Blue: light grey, cobalt, top tabs, progress rings, Today as a table, assistant panel.
4. Soft Bento: pastel gradient, rounded tiles, big assistant card with an ask box.
5. Navy Split: navy left panel (note and scoreboard), light right side with the day as a timeline.
