# Showcase films: voiceover scripts

One script per film, timed to the recorded video. Each line starts at its time and should finish inside its length (about 2.5 words a second). Each film has its own .srt with the same lines and times.

**Voice:** the same voice as the ONE film: warm, confident, unhurried. Say "ONE" as the word one.

**Music:** the same family as the ONE film so the set matches: modern, hopeful, 95-105 BPM, ducked about 10 dB under the voice. A small lift on each new feature; resolve on "Part of ONE" and hold 2 seconds.

Lines that say "Coming soon" are features not built yet; keep those words.
